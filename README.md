# SMART TECK ORBIT

**Sua vida organizada. Seu tempo sob controle.**

SMART TECK ORBIT é um aplicativo Android de organização pessoal. Esta primeira entrega cria a base navegável do produto com painel, tarefas, agenda, documentos e assistente demonstrativo.

## Estado atual
- [x] Projeto Android com Kotlin e Jetpack Compose
- [x] Navegação entre quatro áreas principais
- [x] Painel inicial e criação de tarefas em memória
- [ ] Persistência local (Room/DataStore)
- [ ] Agenda com notificações
- [ ] Importação e leitura de documentos
- [ ] Inteligência artificial e sincronização
- [ ] Assinaturas Google Play Billing com validação no servidor

## Abrir o projeto
Abra a pasta do repositório no Android Studio. Use JDK 17 e Android SDK 35. O Android Studio poderá gerar/baixar o Gradle Wrapper na primeira abertura, caso necessário.

## Privacidade
Ações importantes devem exigir aprovação explícita. O usuário deve poder revisar, corrigir, exportar e excluir seus dados. Não armazene documentos sensíveis sem necessidade.

## Planos planejados
Free, ORBIT Start, ORBIT Plus e ORBIT Ultra. Preços e limites são provisórios e dependem da estimativa de custos. A expiração da assinatura não deve impedir o acesso razoável aos próprios dados.

> Esta é uma base inicial de desenvolvimento. Não é um APK compilado, assinado ou publicado.
